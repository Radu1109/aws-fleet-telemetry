Unit Decomposition

Four independently-bounded units deployed as one integrated serverless application

Unit Boundary Key Responsibilities Status
U1 — Telemetry Core Intake & Processing Validate, deduplicate, canonical identity, alerts (speed >110 km/h, fuel drop >10pp), route history Complete
U2 — Fleet Access Query & Auth Staff fleet map, vehicle state, alerts, route replay, daily reports; third-party JWT auth with object-level vehicle authorization Complete
U3 — Daily Reporting Calculations Distance (haversine), idle time (≤60s cap), fuel used (sum of drops), UTC-day attribution, JSON + CSV download Complete
U4 — Integrated Packaging Infrastructure Terraform IaC (10 modules), GitLab CI/CD (MR/staging/production), monitoring, backup, OIDC federation Complete

Alert Rules
Excessive Speed
Two consecutive readings > 110 km/h in event-time order. A reading ≤ 110 km/h clears the condition.
Sudden Fuel Drop
Fuel level drops > 10 percentage points within any 5-minute window.
Staleness
Vehicle marked stale when no reading received for ≥ 60 seconds.
